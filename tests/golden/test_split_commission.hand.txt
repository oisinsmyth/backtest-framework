Golden worked case for commission on as-traded prices. Commission on a pre-split
historical bar is computed on the raw price, not the split-adjusted one; the test
asserts that the difference from the adjusted-price calculation is nonzero and equals
the hand arithmetic below. Companion to test_split_commission.py.

The pre-split bar, from the committed raw fixture:
  XOP 2020-03-27 (last trading day before the 1-for-4 reverse split of 2020-03-30)
  adjusted-frame close (as yfinance serves it) = 32.12
  as-traded close = 32.12 x 0.25 = 8.03   (as_traded_from_adjusted)

Deploying $32,120 into XOP on that day:
  As traded:          32,120 / 8.03  = 4,000 real shares actually traded
  In adjusted terms:  32,120 / 32.12 = 1,000 phantom shares

IBKR Fixed commission ($0.005/share, $1 min, 1% cap):
  as-traded: max(0.005 x 4,000, 1.00) = 20.00 ; cap 0.01 x 4,000 x 8.03  = 321.20 -> 20.00
  adjusted:  max(0.005 x 1,000, 1.00) =  5.00 ; cap 0.01 x 1,000 x 32.12 = 321.20 ->  5.00

  Difference = 20.00 - 5.00 = 15.00  (nonzero; the 4x share-count factor the reverse
  split hides). Same notional, same day, same broker: using adjusted prices understates
  commission 4x. A per-share commission depends on the share count, which split
  adjustment changes, so it must be computed on as-traded prices.
