THE MACD GOLDEN MASTER — hand arithmetic
=============================================================================
Computed from the stated rules with exact rational arithmetic, without running
the codebase (D39/D77). If `research/macd.py` and this file disagree, one of
them is wrong about what MACD IS, and that argument happens here.

Every number below is a DYADIC RATIONAL — a fraction whose denominator is a
power of two — so every one of them is exactly representable in IEEE-754 double
and the golden test asserts `==`, not `approx`. That is not luck; the setup was
chosen for it, and the choices that buy it are stated in SETUP.

SETUP
-----
parameters        MACD(fast=3, slow=7, signal=3)
                  alpha = 2/(n+1)  =>  fast 1/2, slow 1/4, signal 1/2.
                  Chosen because every alpha is a power of two. At 12/26/9 the
                  alphas are 2/13 and 2/27 and NOTHING is exact, so a hand file
                  at the default triple could only ever be approximate.
                  The default's numerical behaviour is pinned separately, in
                  tests/unit/test_macd.py, where approximation is honest.
seeding           Both EMAs SMA-seeded at index slow-1 = 6, EACH OVER ITS OWN
                  WINDOW: the slow leg over closes[0:7], the fast leg over the
                  LAST 3 closes, closes[4:7]. Not closes[0:3].
                  Signal line SMA-seeded at index 6+3-1 = 8, over macd[6:9].
closes            Integers, chosen so that sum(closes[0:7]) = 721 = 7 x 103 and
                  sum(closes[4:7]) = 315 = 3 x 105 divide EXACTLY, and so that
                  sum(macd[6:9]) = 117/16 divides exactly by 3. That last one is
                  why close[8] is 112 and not 111: at 111 the signal seed is
                  113/48, which is not dyadic, and the file would have to round.
scores            rung 2 (zero line)   = macd
                  rung 1 (signal line) = macd - signal      [the histogram]
positions         sign of the score, ties flat, evaluated on close(t).
                  Both arms start at the LADDER'S COMMON START = 8, which is
                  warm_up_bars(3,7,3, include_burn_in=False) = (7-1)+(3-1).
                  If each arm started at its own first defined bar the two
                  series would cover different spans and could not be compared.
burn-in           OFF for this file. `burn_in_bars` moves only the first bar the
                  strategy may ACT on; it never touches a single number above.
                  Turning it off is what lets a 16-bar file pin the classic,
                  live-seed MACD — which is exactly the regime where the seed
                  convention is visible and therefore what a golden should pin.

THE SEEDS
---------
ema_slow[6] = (100+101+103+102+104+106+105)/7 = 721/7 = 103         exact
ema_fast[6] = (104+106+105)/3                = 315/3 = 105          exact
macd[6]     = 105 - 103 = 2

signal[8]   = (macd[6] + macd[7] + macd[8])/3
            = (2 + 9/4 + 49/16)/3 = (117/16)/3 = 39/16 = 2.4375     exact

THE RECURSION, ONE LINE PER BAR
--------------------------------
ema_slow[t] = ema_slow[t-1] + (1/4)(close[t] - ema_slow[t-1])
ema_fast[t] = ema_fast[t-1] + (1/2)(close[t] - ema_fast[t-1])
signal[t]   = signal[t-1]   + (1/2)(macd[t]  - signal[t-1])

WHAT THIS PINS
--------------
1. alpha = 2/(n+1), applied to fast, slow AND the signal line.
2. The seed convention, exactly: BOTH EMAs seeded at index slow-1 = 6, the fast
   leg over its OWN last 3 closes (104,106,105) and not over closes 0..2. Seeding
   the fast leg from bar 0 would give ema_fast[6] a different value and every
   number below it would move.
3. The signal line is an EMA of the MACD, not of price, seeded over the first 3
   MACD values.
4. The score is evaluated on close(t) — a completed bar. Fill timing is the
   caller's business; nothing here reads close(t+1).
5. `burn_in_bars` moves only the first tradeable bar. Every number in the
   recursion above is identical with it on and off.
6. THE NESTING, AND ITS CONSEQUENCE. Rung 1 is rung 2's series minus an EMA of
   itself, and at t=9 and t=10 THE TWO ARMS HOLD OPPOSITE POSITIONS on the same
   bars. That is not a rounding artifact: the MACD is still positive (trend up)
   while the histogram has gone negative (trend decelerating). It is the
   clearest small-scale demonstration of D217's central claim that the signal
   line converts a trend-LEVEL rule into a trend-ACCELERATION rule, and if a
   future edit ever makes the two arms agree everywhere, the ladder has stopped
   being a ladder and this file goes red.
