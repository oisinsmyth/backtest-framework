# Conflicts and agreements — how to read this folder

[← consolidated index](../00-INDEX.md)

**Two different rules apply in this folder and mixing them is the one mistake to avoid.**

| between | rule | file |
|---|---|---|
| **research ↔ research** | **RECORDED, NOT ADJUDICATED.** All readings stand. An agent's preference is reported as that agent's preference. Only the principal retires either side | [01-register](01-register.md) · [04-inside-briefs](04-inside-briefs.md) |
| **research ↔ this repo** | **THE REPO'S MEASUREMENT IS TAKEN AS TRUE**, per the principal, 2026-09-10. The research reading is **kept and marked**, never deleted | [02-versus-repo](02-versus-repo-measurements.md) |
| **research → this repo, agreeing** | recorded, because a register of only disagreements makes research look like noise | [03-agreements](03-agreements.md) |

---

## The four files

**[`01-register.md`](01-register.md)** — every cross-lane conflict ID (`C1`–`C17`, `D1`–`D10`,
`E1`–`E11`, `F1`–`F7`, `G1`–`G6`), one line each, with a link to the record that holds the full
readings and a marker for the ones that touch a repo measurement. **51 entries. This is a lookup
table.**

**[`02-versus-repo-measurements.md`](02-versus-repo-measurements.md)** — **the file to read first.**
Twelve places where external research and a study run here point different ways. Three are settled by
a measurement that already exists, four dissolve once the objects are named, five are open and cheap.

**[`03-agreements.md`](03-agreements.md)** — eleven places an outside route landed on a number this
programme had already measured, or supplied its missing half. Two of them became sections of
`FINDINGS.md` **after being re-derived here**, which is the only way anything crosses.

**[`04-inside-briefs.md`](04-inside-briefs.md)** — pointers to the conflicts each lane logged inside
its own brief. These never got IDs and would otherwise be invisible.

## The shape of the conflict set, stated once

- **Nine of the 51 are two primary sources, or one source, disagreeing with itself** — `C3`, `C4`,
  `C16`, `D8`, `E4`, `E5`, `E9`, `F7`, `G6`. **That is a fact about the record, not an error by an
  agent.**
- **Five are documentation against code, and the code was right every time** (`E9`, `F3`, `G6`×3).
  **The class should now be assumed, not discovered.**
- **Three are draft against published, and twice the sign flipped** (`D8`, `F5`, `F7`) — and in one
  case **the freely-indexed version is the one that says the more useful thing** (`K6` §1.3).
- **The campaign's own central conflict, `F1`, is between two of its own lanes**, same era, both
  fully controlled — which is the construction-dispersion finding (`C2`) happening to the campaign
  rather than being read about.
