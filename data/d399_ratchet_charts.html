The Ratcheted Trendline

A trendline whose gradient is sticky and whose intercept moves only when price breaks it. Drawn on real daily candles from the 1,573-name mining fixture, log price axis, so a constant-gradient line is a straight line.

The rule, as specified

hold G, the gradient. each bar:

    if |g_fresh − G| > h    RE-ANCHOR   G := g_fresh, line := the fresh OLS fit
                                       the ratchet resets

    otherwise               ADVANCE     line := line + G

                            and if price violates the line,
                            push the intercept away from price
                            exactly far enough that the trend is
                            respected again
δ 1e-3 · min |gradient|, both slopes · 28.7%/yr h 1e-3 · gradient dead band k 3 window 252 respects the wick fits on log price
support line (through swing lows) resistance line (through swing highs) re-anchor — gradient changed intercept pushed state UP state DOWN
